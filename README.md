# NLP & LLMs (Large Language Models)

Natural Language Processing (NLP) and Large Language Models (LLMs) are transforming cybersecurity. From automating report generation to extracting threat intelligence from unstructured data, generative AI offers significant capability upgrades.

This section highlights my knowledge of setting up, communicating with, and integrating LLMs into programmatic workflows.

## Contents
- `llm_security_analyst.py`: A Python script that interfaces with a locally hosted LLM (via Ollama). Self-hosting LLMs is critical in cybersecurity to maintain data privacy and confidentiality when analyzing sensitive logs or alerts. The script automatically prompts the LLM to analyze simulated SSH brute-force logs.
